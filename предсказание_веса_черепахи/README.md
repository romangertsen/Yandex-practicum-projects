# TurtleCV — предсказание массы морских черепах

## Описание проекта

Центр исследования и реабилитации морских черепах «Тортилла» совместно с лабораторией океанографии разрабатывает систему компьютерного зрения TurtleCV, позволяющую бесконтактно измерять параметры морских черепах.

Традиционное взвешивание крупных черепах является стрессовой процедурой для животных и может быть опасным для персонала. Поэтому возникает задача построения модели машинного обучения, которая будет предсказывать массу черепахи по измерениям её габаритов.

В рамках проекта рассматривается задача **регрессии** — прогнозирование массы зелёных морских черепах (Chelonia mydas) на основе данных, полученных системой компьютерного зрения.

Модель должна быть **линейной**, чтобы её можно было использовать в составе прибора TurtleCV в виде простой формулы.

---

## Цель исследования

Построить линейную модель регрессии, способную предсказывать массу морской черепахи по измерениям её габаритов с достаточной точностью для практического использования в реабилитационном центре.

---

## Данные

Файл: `turtles.csv`

Основные признаки:

- shell_length — длина панциря
- shell_width — ширина панциря
- head_length — длина головы
- head_width — ширина головы
- flipper_length_1–4 — длины ласт
- flipper_width_1–4 — ширины ласт
- circle_count — число колец роста
- measure_count — число измерений
- shell_crack — наличие трещин
- weight — масса (целевая переменная)

Технические поля:
- id
- registration_number
- timestamp
- binomial_name

---

## Этапы работы

### 1. Исследовательский анализ данных (EDA)
- анализ структуры данных
- проверка типов данных
- поиск пропусков и дубликатов
- анализ распределений признаков
- анализ корреляций

### 2. Предобработка данных
- удаление технических признаков
- обработка пропусков
- преобразование признаков
- создание агрегированных признаков (при необходимости)
- масштабирование данных

### 3. Обучение моделей
Были обучены несколько линейных моделей:

- LinearRegression
- Ridge
- Lasso

Данные были разделены:
- train — 60%
- validation — 20%
- test — 20%

---

## Метрики качества

Для оценки моделей использовались:

- MAE
- MAPE
- R²

---

## Результаты

 - MAE: 4.73
 - MAPE: 5%
 - R²: 0.97

Модель объясняет большую часть вариативности массы черепах и может быть использована в системе TurtleCV.

---

## Важность признаков

Наибольший вклад в предсказание массы вносят:

- длина панциря
- ширина панциря
- размеры ласт
- размеры головы
- количество колец панциря

---

## Функция предсказания массы

После обучения модели реализована функция прогнозирования массы черепахи по признакам на основе формулы линейной регрессии.

Это позволяет встроить модель непосредственно в устройство TurtleCV.
