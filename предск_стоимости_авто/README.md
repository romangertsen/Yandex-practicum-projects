# AutoValue AI: прогнозирование рыночной стоимости автомобилей

## Описание проекта

В этом проекте решается прикладная задача стартапа AutoValue AI, который развивает сервис мгновенного выкупа автомобилей на рынке подержанных машин. Бизнес-модель компании предполагает, что клиент заполняет анкету в приложении, алгоритм за секунду оценивает стоимость автомобиля, а после быстрой технической проверки клиент сразу получает деньги.

Для компании критически важно, чтобы модель оценки работала быстро, стабильно и точно. Ошибка в прогнозе напрямую влияет на финансовый результат:
- завышение цены приводит к покупке неликвидного автомобиля и прямым убыткам при перепродаже
- занижение цены приводит к потере клиента, который уходит к конкурентам
- медленная оценка ухудшает пользовательский опыт и снижает конверсию

Цель проекта — построить и сравнить модели машинного обучения на базе трех библиотек XGBoost, CatBoost и LightGBM, а затем выбрать лучший инструмент для внедрения в продукт компании.

## Цель проекта

Разработать модель прогнозирования стоимости автомобиля и провести турнир библиотек градиентного бустинга, чтобы:
- выбрать наиболее эффективную библиотеку для внедрения
- минимизировать финансовые риски бизнеса
- обеспечить прозрачность и интерпретируемость модели
- оценить качество модели не только по стандартным метрикам, но и по бизнес-метрикам

## Данные

В проекте используются два набора данных:

### Обучающая выборка
Файл `ds_s16_train_data.csv` содержит историю 8000 прошлых сделок.

### Тестовая выборка
Файл `ds_s16_test_data.csv` содержит 2000 объектов и используется только для финальной проверки качества модели.

## Признаки

Датасет содержит информацию о характеристиках автомобиля и условиях продажи:
- марка автомобиля
- год выпуска
- пробег
- объем двигателя
- тип топлива
- тип трансмиссии
- количество владельцев
- цвет
- наличие сервисной истории
- количество ДТП
- действительность страховки
- макрорегион продажи

Целевая переменная:
- `price_rub` — рыночная стоимость автомобиля в рублях

## Бизнес-метрики

В проекте, помимо стандартных метрик качества регрессии, используются две специальные бизнес-метрики.

### Overpricing Rate
Доля случаев, когда модель завышает цену автомобиля более чем на 20 процентов относительно реальной стоимости. Для бизнеса это означает риск опасной переплаты и потенциальных убытков при перепродаже.

### Underpricing Loss
Суммарная недооценка стоимости в случаях, когда модель занижает цену более чем на 20 процентов. Для бизнеса это означает упущенную выгоду и потерю клиентов, которые могут уйти к конкурентам.

## Этапы работы

## 1. Анализ данных

На первом этапе проводится исследование структуры данных:
- анализ распределения целевой переменной `price_rub`
- проверка пропусков и базового качества данных
- анализ взаимосвязей между признаками
- визуализация распределений и закономерностей

## 2. Предобработка данных

Для корректного и честного сравнения моделей выполняется единая схема подготовки данных:
- выделение признаков и целевой переменной
- разбиение на обучающую, валидационную и тестовую выборки
- обработка категориальных и числовых признаков
- обеспечение одинаковых условий для всех библиотек

## 3. Базовое обучение моделей

На этом этапе проводится первый раунд турнира библиотек. Обучаются три модели:
- XGBoost
- CatBoost
- LightGBM

Они сравниваются на одних и тех же выборках по следующим метрикам:
- RMSE
- MAE
- R²
- Overpricing Rate
- Underpricing Loss

## 4. Подбор гиперпараметров

Для каждой библиотеки выполняется оптимизация гиперпараметров с помощью Optuna. Подбор проводится в рамках заданных диапазонов параметров, чтобы получить лучшую версию модели внутри каждой библиотеки.

В ходе оптимизации рассматриваются:
- скорость обучения
- глубина деревьев
- количество итераций
- параметры регуляризации
- библиотекоспецифичные настройки

Основная метрика оптимизации — MAE

## 5. Интерпретация модели и бизнес-анализ

После выбора лучших моделей выполняется анализ их поведения:
- оценка важности признаков с помощью SHAP
- выделение топ-5 факторов, сильнее всего влияющих на стоимость автомобиля
- анализ случаев завышения и занижения цены
- анализ ошибок по маркам автомобилей и регионам

Этот этап позволяет понять, насколько выводы модели совпадают с бизнес-логикой и где модель наиболее уязвима

## 6. Финальная проверка

Лучшая оптимизированная модель проходит финальную проверку на отложенном тестовом наборе `ds_s16_test_data.csv`. Сравниваются результаты на валидации и тесте, чтобы убедиться в стабильности модели и отсутствии переобучения

Проект показывает, как можно перевести экспертную ручную оценку автомобилей в автоматизированную ML-систему, способную работать быстро и в масштабе. Такое решение может стать основой для цифрового продукта мгновенного выкупа автомобилей и поддерживать ключевые бизнес-процессы компании:
- автоматическую оценку стоимости
- снижение риска убыточных сделок
- уменьшение оттока клиентов
- масштабирование сервиса без роста штата оценщиков

## Итог

В проекте проводится сравнение трех популярных библиотек градиентного бустинга для задачи оценки стоимости автомобилей. Основная задача — определить, какая из них лучше всего подходит для внедрения в продукт AutoValue AI с учетом как точности прогноза, так и бизнес-рисков, связанных с завышением и занижением цены
