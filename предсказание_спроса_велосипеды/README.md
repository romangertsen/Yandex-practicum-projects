# BikeSouth — прогнозирование спроса на аренду велосипедов

## Описание проекта

Компания BikeSouth развивает систему городского велопроката на юге России. Для стабильной работы сервиса необходимо точно прогнозировать почасовой спрос на велосипеды.

Ранее использовалась модель линейной регрессии, однако она показала низкое качество, так как не учитывает сложные зависимости между погодными условиями и поведением пользователей.

---

## Цель исследования

Построить модель машинного обучения, способную точно предсказывать почасовой спрос на аренду велосипедов с учётом нелинейных зависимостей между признаками.

---

## Данные

Файлы:
- `ds_s14_train_data.csv` — обучение и валидация
- `ds_s14_test_data.csv` — финальная оценка

Целевая переменная:
- `Rented Bike Count` — количество арендованных велосипедов в час

Основные признаки:

- Temperature — температура воздуха
- Humidity — влажность
- Windspeed — скорость ветра
- Solar Radiation — солнечная радиация
- Rainfall, Snowfall — осадки
- Seasons — время года
- Holiday — праздничные дни
- Time_Period — временные интервалы суток

---

## Этапы работы

### 1. Исследовательский анализ данных (EDA)

- анализ структуры данных
- проверка типов данных
- анализ распределения целевой переменной
- анализ взаимосвязей между признаками
- выявление ключевых факторов, влияющих на спрос

### 2. Предобработка данных

- обработка категориальных признаков
- проверка на пропуски
- подготовка данных для моделей
- формирование обучающих и валидационных выборок
- контроль отсутствия утечек данных

### 3. Обучение моделей

Были обучены следующие модели:

- kNN Regressor
- Decision Tree Regressor

В качестве baseline использовалась линейная регрессия, предоставленная заказчиком.

---

## Метрики качества

Для оценки моделей использовались:

- RMSE
- MAE
- R²

Оптимизация гиперпараметров проводилась с использованием Optuna и кросс-валидации (5 фолдов).

---

## Результаты

Лучшая модель: kNN

- MSE: 148238.436
- RMSE: 385.017
- MAE: 260.729
- R²: 0.638

Модель показала улучшение качества по сравнению с линейной регрессией и лучше учитывает нелинейные зависимости в данных.

---

## Важность признаков

Наибольшее влияние на спрос оказывают:

- температура
- солнечная радиация
- время суток
- осадки

---

## Выводы

- Нелинейные модели существенно превосходят линейную регрессию
- Влияние погодных факторов на спрос носит комплексный характер
- Учет взаимодействий признаков критически важен для точного прогнозирования
- Разработанная модель может быть использована для оптимизации распределения велосипедов
