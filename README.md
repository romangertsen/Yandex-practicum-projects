# Портфолио проектов Яндекс.Практикум  
**«Специалист по Data Science»**

В данном репозитории представлены проекты, выполненные в ходе обучения по программе профессиональной переподготовки **Специалист по Data Science** в Яндекс Практикуме.  
Основной язык программирования — `python`

---

## Проекты

| Проект | Описание | Навыки и инструменты |
|--------|----------|---------------------|
| [предсказание_вероятности_отклика_CTR](./предсказание_вероятности_отклика_CTR) | Модель бинарной классификации для предсказания клика по рекламному объявлению и калибровка вероятностей | pandas, numpy, sklearn, PR-AUC, LogLoss, калибровка вероятностей, GridSearchCV, машинное обучение | 
| [предсказание_веса_черепахи](./предсказание_веса_черепахи) | Линейная регрессия для бесконтактного предсказания массы морских черепах по данным компьютерного зрения | pandas, numpy, sklearn, линейная регрессия, feature engineering, MAE, MAPE, R² | 
| [предсказание_возр_группы](./предсказание_возр_группы) | Модель классификации возрастной категории пользователя по цифровому поведению | pandas, numpy, sklearn, SVC, LogisticRegression, feature engineering, One-Hot Encoding, GridSearchCV | 
| [удержание_пользователей_Яндекс_Афиши](./удержание_пользователей_Яндекс_Афиши) | Исследовательский анализ данных пользователей Яндекс Афиши и факторов повторных покупок | pandas, numpy, matplotlib, seaborn, phik, SQL, EDA, продуктовая аналитика | 
| [предсказание_спроса_на_велосипеды](./предсказание_спроса_на_велосипеды) | Прогнозирование спроса на велосипеды с использованием моделей временных рядов и регрессии | pandas, numpy, sklearn, временные ряды, feature engineering, RMSE, MAE, регрессия |
