# Прогнозирование отмен бронирований в сети отелей UrbanStay

## Описание проекта

В этом проекте решается бизнес-задача сети отелей **UrbanStay**: снижение финансовых потерь, связанных с частыми поздними отменами бронирований. По данным заказчика, доля отмен достигает **30% и более**, из-за чего фактическая загрузка отелей держится на уровне **60–70%** вместо целевых **80%+**.

Основная идея проекта — построить **ML-модель**, которая заранее оценивает вероятность отмены бронирования. Это позволяет отелю заранее выявлять рискованные брони и принимать превентивные меры: предлагать клиентам альтернативные условия, корректировать стратегию овербукинга и снижать вероятность простоя номеров.

## Цель проекта

Разработать модель машинного обучения для прогнозирования вероятности отмены бронирования и подготовить решение, которое поможет:

- заранее выявлять бронирования с высоким риском отмены;
- снижать долю поздних отмен;
- повышать загрузку отелей;
- минимизировать финансовые потери;
- оценивать экономическую эффективность внедрения модели.

## Данные

В проекте используются два источника данных:

### 1. История бронирований (`hotel_bookings`)
Таблица содержит информацию о бронированиях номеров:
- канал продаж;
- количество взрослых и детей;
- информация о прошлых отменах;
- стоимость бронирования;
- число дней до заезда;
- количество ночей в будние и выходные;
- тип питания;
- тип номера;
- специальные запросы клиента;
- статус бронирования.

### 2. История отзывов (`hotel_reviews`)
Таблица содержит данные о предыдущем опыте проживания клиента:
- дата отзыва;
- оценка проживания;
- текст отзыва.

Отзывы используются для извлечения дополнительных признаков, характеризующих предыдущий пользовательский опыт.

## Этапы работы

### 1. Подготовка данных
На первом этапе выполняется загрузка данных из PostgreSQL, исследовательский анализ данных и подготовка таблиц к моделированию. Также проводится объединение таблицы бронирований с таблицей отзывов по логике ближайшего предыдущего отзыва клиента на момент нового бронирования.

### 2. Feature Engineering
В рамках проекта создаются дополнительные признаки на основе:
- параметров бронирования;
- информации о прошлой активности клиента;
- текстов отзывов.

Для работы с текстами отзывов используется векторизация, что позволяет превратить текстовую информацию в числовые признаки и использовать её в моделях машинного обучения.

### 3. Моделирование
Для решения задачи классификации использовались несколько моделей машинного обучения:

- **CatBoost**
- **Random Forest**
- **LightGBM**

Модели сравниваются между собой с точки зрения применимости к бизнес-задаче прогнозирования отмен бронирований. Лучшая модель в проекте — **CatBoost**.

### 4. Настройка модели
Для подбора параметров моделей применяется:
- разбиение данных на обучающую, калибровочную и тестовую выборки;
- кросс-валидация;
- оптимизация гиперпараметров с помощью **Optuna**.

После выбора лучшей модели выполняется:
- калибровка вероятностей;
- подбор оптимального порога классификации;
- анализ важности признаков.

### 5. Оценка экономической эффективности
Отдельный этап проекта посвящён оценке бизнес-эффекта от внедрения модели. Рассматриваются следующие показатели:
- доля отмен бронирования;
- загрузка отеля;
- прирост дохода (**Incremental Revenue**).

## Используемые модели

В проекте были протестированы три модели:

1. **CatBoost**  
   Используется как основная и лучшая модель проекта. Хорошо работает с табличными данными, устойчиво обрабатывает категориальные признаки и показывает сильные результаты без сложной предобработки.

2. **Random Forest**  
   Применяется как базовая ансамблевая модель для сравнения качества и устойчивости результатов.

3. **LightGBM**  
   Используется как градиентный бустинг для сравнения с CatBoost и оценки качества на табличных данных.

## Практическая ценность проекта

Проект демонстрирует, как методы машинного обучения можно использовать для решения прикладной бизнес-задачи в гостиничной индустрии. Разработанное решение может быть использовано для:

- снижения числа поздних отмен;
- более точного управления бронированиями;
- повышения загрузки отелей;
- сокращения потерь от простоя номеров;
- повышения устойчивости бизнеса.

## Структура проекта

- обучение и сравнение моделей;
- калибровка вероятностей;
- подбор порога;
- оценка экономической эффективности;
- интерпретация факторов, влияющих на отмену бронирования.

## Итог

В проекте разработано решение для прогнозирования отмен бронирований в сети отелей UrbanStay. Для моделирования использовались **CatBoost**, **Random Forest** и **LightGBM**, при этом **CatBoost** показал наилучшее качество и был выбран в качестве итоговой модели.
