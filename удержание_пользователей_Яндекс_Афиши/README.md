# Анализ лояльности пользователей Яндекс Афиши
## Исследовательский анализ поведения пользователей (EDA)

---

## Описание проекта

В данном проекте проводится исследовательский анализ данных сервиса **Яндекс Афиша**, направленный на изучение поведения пользователей и факторов, влияющих на их возврат на платформу.

Яндекс Афиша позволяет пользователям узнавать о мероприятиях и покупать билеты. Для команды маркетинга важно не только привлекать новых пользователей, но и **повышать удержание клиентов**.

Цель анализа — понять, какие характеристики пользователей и их заказов связаны с повторными покупками.

Проект является примером **EDA-исследования в продуктовой аналитике**, где основная задача — выявление закономерностей в данных и формирование бизнес-рекомендаций.

---

## Цель проекта

Выявить факторы, связанные с повторными заказами пользователей Яндекс Афиши, на основе анализа их профиля и истории покупок.

---

## Используемые данные

Данные были выгружены из SQL-базы Яндекс Афиши и включают информацию о:

- заказах пользователей
- выручке сервиса
- количестве билетов
- времени заказов
- устройстве пользователя
- регионе проведения мероприятий
- билетных операторах
- жанрах мероприятий

Дополнительно использовался датасет:
- `final_tickets_tenge_df.csv` — курс тенге к рублю.

---

## Этапы проекта

### 1. Загрузка данных
- подключение к SQL-базе
- выгрузка данных в pandas
- первичный анализ структуры данных

---

### 2. Предобработка данных
- перевод выручки из тенге в рубли
- обработка пропусков
- преобразование типов данных
- анализ категориальных признаков
- фильтрация выбросов по `revenue_rub`
- проверка корректности данных

---

### 3. Создание профиля пользователя

Для каждого пользователя были рассчитаны агрегированные признаки:

- дата первого заказа
- дата последнего заказа
- устройство первого заказа
- регион первого заказа
- билетный оператор первого заказа
- жанр первого мероприятия
- общее число заказов
- средняя выручка с заказа
- среднее число билетов
- средний интервал между заказами

Также были созданы признаки:
- `is_two` — пользователь совершил ≥2 заказов
- `is_five` — пользователь совершил ≥5 заказов

---

### 4. Исследовательский анализ данных

Были исследованы:

#### Признаки первого заказа
- тип мероприятия
- устройство
- регион
- билетный оператор

#### Поведенческие признаки
- средняя выручка с заказа
- среднее число билетов
- количество заказов
- интервалы между покупками

#### Временные характеристики
- день недели первого заказа
- средний интервал между покупками

#### Корреляционный анализ
Использовался коэффициент **phi_k** для оценки связи:
- признаков профиля пользователя
- количества заказов

---

## Основные результаты анализа

- Большая часть пользователей совершает **только один заказ**
- Пользователи с более высокой средней выручкой чаще возвращаются
- Увеличение среднего количества билетов связано с большей вероятностью повторных покупок
- Интервал между заказами связан с удержанием пользователей
- Некоторые категории мероприятий показывают более высокий уровень возврата
- Корреляционный анализ выявил признаки, связанные с количеством заказов
