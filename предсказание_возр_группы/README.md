# Age Group Prediction from User Digital Behavior
## ML-проект для компании «Йети»

---

## Описание проекта

В  проекте решается задача **многоклассовой классификации** — определение возрастной категории пользователя по его цифровому поведению.

Компания «Йети» использует возрастной таргетинг в рекламной сети. Для повышения эффективности рекламных кампаний необходимо автоматически определять возрастную категорию пользователя на основе его активности в интернете.

В качестве источника данных используются:
- логи посещений сайтов,
- взаимодействие пользователя с рекламой,
- характеристики устройства,
- поведенческие признаки.

Модель позволяет сегментировать пользователей по возрасту и показывать рекламу релевантной аудитории.

---

## Цель проекта

Построить модель машинного обучения, способную предсказывать возрастную категорию пользователя по данным о его активности в цифровой среде.

---

## Используемые данные

Проект использует несколько таблиц:

- `ds_s13_users.csv` — возрастная категория пользователя
- `ds_s13_visits.csv` — логи посещений сайтов
- `ads_activity.csv` — активность взаимодействия с рекламой
- `surf_depth.csv` — глубина просмотра сайтов
- `primary_device.csv` — основное устройство пользователя
- `cloud_usage.csv` — использование облачных сервисов

Объединение данных выполняется по `user_id`.

---

## Feature Engineering

В проекте были созданы агрегированные признаки:

- доля посещений категорий сайтов
- распределение активности по времени суток
- среднее число сессий пользователя
- поведенческие признаки взаимодействия с рекламой
- признаки устройства пользователя

Для предотвращения мультиколлинеарности были удалены линейно зависимые признаки.

---

## Модели

- DummyClassifier (baseline)
- Logistic Regression
- Support Vector Classifier (SVC)

Использовались:
- Stratified K-Fold
- GridSearchCV
- Pipeline
- ColumnTransformer
- Sequential Feature Selector

---

## Метрики качества

Основная метрика:
- **F1-macro**

Дополнительные:
- Precision-macro
- Recall-macro

Макро-усреднение используется для равного учета всех возрастных категорий.

---

## Результаты

### Baseline

DummyClassifier используется как точка отсчёта.

| Metric | Value |
|-------|------|
| F1-macro | 0.0937 |

---

### Лучшая модель

Лучший результат показала модель **SVC**.

Результаты на тестовой выборке:

| Metric | Value |
|-------|------|
| F1-macro | 0.8919 |
| Precision-macro | 0.8965 |
| Recall-macro | 0.8883 |

Модель значительно превосходит baseline и удовлетворяет требованиям проекта.

---

## Итог

Построена модель машинного обучения для определения возрастной категории пользователей по их цифровому поведению.

Результаты показывают, что поведенческие признаки посещения сайтов и взаимодействия с рекламой позволяют эффективно сегментировать аудиторию.

Модель может быть использована для  таргетной рекламы.
