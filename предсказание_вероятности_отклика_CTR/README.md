# Ad Click Prediction & Probability Calibration (CTR Model)

## Описание проекта

Проект посвящён построению модели машинного обучения для прогнозирования клика по рекламному объявлению (CTR — Click-Through Rate) и последующей калибровке предсказанных вероятностей.

Корректная оценка вероятности клика является критически важной задачей для рекламных платформ, использующих аукционные механизмы размещения рекламы. Ошибки в вероятностях приводят к финансовым потерям:
- переоценка CTR → переплата за показы,
- недооценка CTR → упущенный доход.

Цель проекта — построить не только точную модель классификации, но и **хорошо откалиброванную модель вероятностей**, пригодную для использования в рекламных аукционах.

---

## Задача машинного обучения

**Тип задачи:** бинарная классификация  
**Целевая переменная:** `click`  
**Задача:** предсказать вероятность клика по рекламному баннеру.

Модель должна:
- хорошо различать клики и не-клики,
- выдавать корректные вероятности,
- быть устойчивой к дисбалансу классов.

---

**Приложение**
- app_id

- device_model

**Целевая переменная**

## Этапы проекта

### 1. Исследовательский анализ данных
- анализ структуры датасета
- исследование распределения целевой переменной
- анализ категориальных и числовых признаков
- проверка пропусков и выбросов

---

### 2. Предобработка данных

Используемый пайплайн:

- заполнение пропусков
- One-Hot Encoding для низкой кардинальности
- Target Encoding для высококардинальных признаков
- масштабирование числовых признаков
- разделение на train / validation / test

---

### 3. Отбор признаков

Использованы:
- корреляционный анализ
- фильтрационные методы
- Sequential Feature Selection

Цель — уменьшить переобучение и повысить устойчивость модели.

---

### 4. Обучение моделей

Были обучены:

- Logistic Regression
- Linear SVM

Гиперпараметры подбирались через **GridSearchCV**.

Валидация:
- Stratified K-Fold

---

### 5. Калибровка вероятностей

Для лучшей модели выполнена калибровка:

- Calibration curve
- Isotonic Regression

Оценка:
- Brier score
- ECE
- MCE

Калибровка позволила улучшить соответствие вероятностей реальным частотам кликов.

---

## Результаты

Лучшая модель:

- Logistic Regression: PR-AUC 0.3928
